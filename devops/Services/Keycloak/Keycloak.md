# Keycloak

Keycloak is an identity and access management system, which allows to apply authentication to applications and secure services with minimum effort.

Provided features are:
 - Single-Sign On: users can authenticate to Keycloak rather than individual applications, which means that several applications will have one login form providing access to all of them. This also applies to single-sign out.
 - Identity Brokering and Social Login: allows to enable login with social networks
