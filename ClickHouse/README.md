ClickHouse is a Yandex Column-Oriented database, dramatically effective with grouping, filtering, aggregation on a large datasets.

Other advantages:
1. Effective in compressing data due to column orientation.
2. Effective in CPU usage: it processes data with vectors, and not by single values, which allows to better use modern CPU's.
3. Scalable (vertically and horizontally)
4. SQL support
5. Different table engines for different purposes
6. Extended analytics functions
7. Open-Source <3
8. Reliable and fault-tolerant.
